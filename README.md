# personas_crud

Este proyecto es una aplicación en Python que permite:

✅ Agregar personas con metas de ahorro  
✅ Editar, listar y eliminar usuarios  
✅ Guardar los datos en un archivo JSON  
✅ Funciona como un CRUD (Create, Read, Update, Delete) básico

---

## Requisitos

- Python 3.10 o versiones siguientes

## Cómo ejecutar

Abre la terminal en la carpeta del proyecto y ejecuta:

```bash
python Listas_nombres_con_menu.py
